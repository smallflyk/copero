## How to redeem a Mystery Gift code

Start Pokémon Champions and finish the tutorial, then create a battle team. The supplied redemption guide says Mystery Gifts are not available immediately and that these two steps unlock the feature. Return to the title screen after the feature is available.

At the title screen, press the A button, select **Submenu**, then select **Mystery Gifts**. Enter the serial code exactly as shown and choose **Confirm**. Do not add spaces, change letters to numbers, or rely on a screenshot that cuts off part of the code.

## Serial codes and mailbox gifts are different

The mobile launch reward for Raichu, Raichunite X, and Raichunite Y was an in-game mailbox distribution. The official announcement gave it a June 17 through September 1, 2026 window and did not instruct players to type a serial code. It therefore does not belong in the active-code table.

This distinction prevents a common source of fake codes. A real gift may be delivered automatically, through the mailbox, through a campaign, or through a typed serial code. If an announcement does not show a code, this site will not create a code-shaped placeholder for it.

## Why a valid code may fail

First compare the current time with the stated end date and its time zone, if one is provided. Then confirm that every `0`, `1`, letter, and number matches the published string. The collected roundup does not document case-insensitive entry, so exact transcription is the safest approach.

A code may also have been redeemed already, may require network access, or may be affected by account or region rules. Those restrictions are not fully described in the research and are therefore **Pending confirmation** for each distribution. If the Mystery Gifts menu is missing, finish the tutorial and create a battle team before troubleshooting the code itself.
